# 🕷️ Spider-Man Project

A visually engaging landing page inspired by the **Spider-Man universe**, developed as a practical project to strengthen front-end development skills and improve visual composition.

This project focuses on layout structure, modern styling, and basic interactivity, delivering an immersive and responsive experience inspired by a popular pop culture theme.



## 🧠 What I learned

* Structuring semantic layouts using **HTML5**
* Creating modern and responsive designs with **CSS3**
* Implementing basic interactions and behaviors using **JavaScript**
* Enhancing visual hierarchy, spacing, and UI consistency
* Improving responsiveness for different screen sizes
